ADDITIONAL CONCEPT CHECK
-------------------------

1. Why are two Person objects created in the
   original inheritance structure?
   Because both Student and Employee inherit separately from Person. When a class inherits from both, it gets two copies of Person—one through Student and one through Employee.

2. What is the diamond inheritance problem?
   It occurs when inheritance forms a diamond:
   Person → Student
   Person → Employee
   Student + Employee → WorkingStudent
   WorkingStudent gets two Person copies, causing ambiguity when accessing Person members.

3. How can virtual inheritance solve the problem?
   Virtual inheritance tells C++ to create only one shared Person object, even though it is inherited through multiple paths.

4. What changes are required in Student and Employee?
   this changes are required here
   class Student : virtual public Person { };
   class Employee : virtual public Person { };

CONCEPT CHECK
-------------------------

1. How does runtime polymorphism work here?
   Runtime polymorphism allows the program to call the overridden function of the derived class through a base class pointer, using the virtual keyword.
   
2. Why is the base class pointer used?
   A base class pointer can point to objects of different derived classes, allowing us to access their overridden functions dynamically.

3. Why should the base class have a virtual destructor?
   A virtual destructor ensures that when a derived object is deleted using a base class pointer, the derived class destructor is also called properly.
   
4. What is the purpose of the template function?
   The template function allows the same function to work with different data types without writing separate functions for each type.

5. What type of exception should be handled if the input amount is invalid?
   A std::invalid_argument exception should be handled when the input amount is invalid.
